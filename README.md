# NexusUI — Premium Next.js + Tailwind CSS Admin Dashboard & UI Kit

A frontend-only, commercial-grade admin dashboard template. No backend, no database,
no API keys — everything runs on local mock data and browser APIs, so you can drop in
your own backend later.

> **Status:** Milestone 1 of 24 complete — project foundation.

## Tech stack

- Next.js (App Router) + React 19
- TypeScript (strict)
- Tailwind CSS v4 (CSS-first configuration)
- Lucide icons

## Requirements

- Node.js 18.18+ (Node 20 LTS recommended)
- npm 9+

## Getting started

```bash
npm install
npm run dev
# open http://localhost:3000
